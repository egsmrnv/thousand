# Thousand

A browser-based implementation of the classic
Thousand (1000) card game.

## Features

- TypeScript game engine
- Configurable game rules
- React-based interface (planned)
- SVG playing cards (planned)
- AI opponents (planned)
- Online multiplayer (planned)

## Development

This project is currently in early development.
